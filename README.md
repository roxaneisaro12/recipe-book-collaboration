# Recipe Book

## About the Project

Recipe Book is a simple website that shares easy-to-follow recipes for everyday cooking. It helps users discover meal ideas and learn how to prepare dishes using clear ingredients lists and step-by-step instructions.

This project was created as part of a collaborative Git and GitHub assignment to practise version control, feature branches, issues, and pull requests.

## Features

- A homepage introducing the Recipe Book.
- A navigation menu linking to the main sections.
- Recipe descriptions and cooking information.
- Ingredients lists for each recipe.
- Numbered preparation instructions.
- An About section describing the project.

## Technologies Used

- HTML5 for the structure and content of the website.
- Git for version control.
- GitHub for repository hosting and collaboration.

## Getting Started

### Prerequisites

You need a web browser and Git installed on your computer. Visual Studio Code is recommended for editing the project.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/roxaneisaro12/recipe-book-collaboration.git
   ```

2. Open the project folder:

   ```bash
   cd recipe-book-collaboration
   ```

3. Open `index.html` in your web browser to view the website.

You can also open the project folder in Visual Studio Code and use the editor to modify the HTML files.

## How to Contribute

1. Check the repository's Issues to find a task.
2. Create a separate feature branch for your assigned issue.
3. Make and test your changes.
4. Commit your work with a clear, descriptive message.
5. Push your branch to GitHub.
6. Open a pull request for review.
7. Wait for approval before merging.

Do not commit directly to the `main` branch.

## Project Goal

The goal is to practise collaborative development using Git and GitHub while building a useful and easy-to-understand recipe website.
